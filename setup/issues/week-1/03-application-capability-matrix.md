# [Week 1] Application — Capability matrix: 10 real tasks

**Pedagogy:** Application · **Milestone:** Week 1 · **Due:** Sunday EOD
**Prerequisite:** Week 1 Knowledge issue complete.

## Project

Run 10 real tasks from your own backlog through Claude Code, properly (context given,
loop closed), and grade each: Reliable / Usable-with-review / Unusable, with a failure
taxonomy. The matrix kills "can Claude do my job?" as a vibe and replaces it with your
own evidence. Applies: the agentic loop, the wired environment, honest grading.

## Detailed Instructions

1. Copy `weeks/week-1/data/capability-matrix-template.md` into your notes.
2. Pick 10 real tasks from your current work: mix sizes and kinds (bugfix, feature,
   refactor, tests, docs, ops). Real inputs, sanitised where needed; no invented toys.
3. Run each through Claude Code with an honest effort: context provided, verify signal
   run where one exists. One task per fresh session.
4. Grade every task with the three-word scale plus a one-line why and the failure mode
   if any.
5. Build the failure taxonomy: group the failures, name each family in your own words,
   count members.
6. Write the two verdict lines (most automatable corner; the family fixable by method).

## Evidence Required

- [ ] The failure taxonomy with counts
- [ ] Both verdict lines
