# [Week 1] Application — The verdict: what Claude Code takes off your plate

**Pedagogy:** Application · **Milestone:** Week 1 · **Due:** Sunday EOD
**Prerequisite:** Week 1 Knowledge issue complete.
**Capstone class:** verdict — capstone step 5 (two committed lines from data), scaled to a week of evidence.

## The Problem

By Sunday you owe yourself a decision, on evidence: which parts of your real work
Claude Code handles reliably, which need review, which aren't worth delegating yet —
and the model mix you'll run in week 2. Opinions don't count; runs do.

The evidence base is 6–8 real tasks from your current backlog, run properly through
Claude Code (context given, loop closed, one task per fresh session) and graded
honestly: Reliable / Usable-with-review / Unusable, with a one-line why. The cost side
is your own `/usage` meters, captured at the end of those same sessions, spikes
annotated the day they happen. Close the week with the graded matrix, a failure
taxonomy (group what failed, name each family in your own words, count members), and
two committed lines: the corner of your job most automatable today, and the failure
family you can fix with method. Then the week-2 mix you'll actually run.

## Constraints

- Real tasks from your current backlog, mixed kinds (bugfix, feature, refactor, tests,
  docs, ops). Sanitise where needed; no invented toys.
- One task per fresh session; give context, run the verify signal where one exists.
- `/usage` captured at each session's end; annotations name causes, never just percentages.
- Templates: `weeks/week-1/data/capability-matrix-template.md` and
  `weeks/week-1/data/usage-log-template.md`.

## Evidence Required

Upload on this issue before closing:

- [ ] The graded matrix — 6–8 rows, all columns filled
- [ ] Usage rows from the same sessions, with at least two spikes annotated with causes
- [ ] The failure taxonomy with counts (at least two families)
- [ ] Both verdict lines, plus the week-2 model mix

## Success Criteria

- [ ] 6+ real tasks, honestly graded (a matrix of straight "Reliable"s will be challenged)
- [ ] Verdict lines are falsifiable — someone could disagree with them on evidence
- [ ] The week-2 mix names what changes and why
- [ ] Evidence uploaded, `<name>:done` label added

## Stuck?

Run `/guide-me` with this issue's link (or paste its text). It coaches you through the
problem one step at a time; it won't solve it for you. If you used it, say "guided" in
your evidence comment — using the net is fine, hiding it isn't.
