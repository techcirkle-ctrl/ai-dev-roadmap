# [Week 1] Application — A second chore leaves your week

**Pedagogy:** Application · **Milestone:** Week 1
**Prerequisite:** Week 1 Knowledge issue complete.
**Capstone class:** build — capstone steps 2–3 (pick + ship), fresh chore, solo.

## The Problem

The capstone walked you through shipping one automation. Your friction log has more
than one entry. Pick the next chore that grated this week and make it stop being
manual: specified in four sentences (trigger, action, systems, proof), built through
your wired environment, shipped at the twice-run bar, then genuinely used at least
three times on real inputs before the week closes. The capstone was the guided rep;
this one is yours end to end.

## Constraints

- The chore comes from your own friction log; the deck's borrow list is a fallback
  only if the log is thin.
- Spec before build: four sentences, the fourth names the proof it worked.
- Twice-run bar: the second run untouched, on fresh input.
- A use counts only on a day the chore genuinely occurred; reruns on the same input don't.

## Evidence Required

Upload on this issue before closing:

- [ ] The spec paragraph
- [ ] The automation itself (script / command file contents, or repo link)
- [ ] Dated proof of 3 real uses (outputs, links, screenshots)
- [ ] One line: did your capstone automation also survive the week?
- [ ] Short note: one decision you made and why

## Success Criteria

- [ ] The spec's fourth sentence names the verify signal
- [ ] 3 genuine uses, each with the named proof
- [ ] Evidence uploaded, `<name>:done` label added

## Stuck?

Run `/guide-me` with this issue's link (or paste its text). It coaches you through the
problem one step at a time; it won't solve it for you. If you used it, say "guided" in
your evidence comment — using the net is fine, hiding it isn't.

~1.5 hours to spec and ship; the uses ride your real work.
