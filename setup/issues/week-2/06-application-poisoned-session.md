# [Week 2] Application — A session went wrong an hour ago and has been confidently wrong since

**Pedagogy:** Application · **Milestone:** Week 2 · **Due:** Sunday EOD
**Prerequisite:** Week 2 Knowledge issue complete.
**Capstone class:** session hygiene under pressure (Act 5's class, on a derailment you cause deliberately)

## The Problem

You know the feeling. Something early in a long session was wrong — a file you pasted that
was out of date, a wrong assumption you did not correct, a failed approach it keeps
circling back to — and everything since has been built on it. The session is not confused.
It is confidently working from something false.

Most people restart and lose the work. This issue is about the other option: recovering
the session with hygiene alone, and knowing which tool applies to which kind of
derailment.

Cause one deliberately, on purpose, so you can watch it happen. Reproducing it is the hard
part, and it is the part that teaches you the early warning signs.

## Constraints

- You must **reproduce** a derailment deliberately, not wait for one to happen. Use
  `weeks/week-2/data/poisoning-drill-template.md` for the shape.
- Recovery uses session hygiene only: `/clear`, focused `/compact`, re-anchoring with
  `@`-refs, a handoff. Restarting the work from scratch does not count as recovery.
- The work in flight must survive. A recovery that loses everything is a restart.
- Name the moment it went wrong, and the earliest signal you could have caught it at.
