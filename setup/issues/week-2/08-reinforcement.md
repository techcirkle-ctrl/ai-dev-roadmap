# [Week 2] Reinforcement — Context is spend, and every document has a scope

**Pedagogy:** Reinforcement · **Milestone:** Week 2 · **Due:** Sunday EOD
**Prerequisite:** Week 2 Knowledge issue complete.

## Why

The habits from this week are invisible ones. Nothing warns you that a document is at the
wrong scope, or that a session has been carrying eight thousand words of dead history for
an hour. The failure is quiet, and quiet failures need a standing instruction to surface
them.

So you write that instruction into your global `~/.claude/CLAUDE.md`, where every session
you ever start will read it. The point is repetition across months, not a note you read
once.

## The Task

Add a paragraph to `~/.claude/CLAUDE.md` (global scope, not the project file) that makes
Claude surface this week's ideology unprompted, in every future session.

It should cause Claude to:

- **Name the scope.** When you add a rule or a document, say which of the five scopes it
  belongs at and why that one rather than project by default.
- **Treat context as spend.** Flag when something being pasted would be better found by
  searching, and say when a session is carrying history it no longer needs.
- **Notice derailment.** Say when the session is working from something established early
  that may no longer hold.
- **Prefer the file over the repeat.** When guidance is being given for the second time in
  a session, say it belongs in a document and name which one.

Write it in your own words. Copying the bullets verbatim produces something that reads like
a checklist and gets ignored. Keep it short: a long paragraph competes for attention with
everything else in the file.
