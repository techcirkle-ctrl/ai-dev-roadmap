# Milestone — Week 1

## Name

Week 1 — Setup + the map: wire everything

## Pace

Self-paced. There is no due date. Work through it at whatever speed real work allows,
and ask for the next week when you are done with this one.

## Learning Objectives

- Explain the agentic loop (gather → act → verify) and read any session by its beats.
- Write well-formed briefs (role, task, constraints, examples, output) that cut
  round-trips and token burn.
- Wire the environment to the zero-copy-paste bar: gh CLI authenticated, MCP servers
  connected, permission baseline set at the right scopes.
- Read and budget usage on Max 5x: windows, weekly cap, model mix, /usage and /context
  (subscriptions show no dollar costs; the readings are relative).
- Triage heavy sessions: /clear when history is done with, focused /compact at
  breakpoints, a handoff file when work outlives the session.
- Name the four disciplines (context, harness, loop, graph) and run one mini-rep of each.
- Ship one real automation through the wired environment and start the friction log.

## Deck

`weeks/week-1/Knowledge.html` (4 acts, 9 hands-ons, 5-step capstone). All week materials
live in `weeks/week-1/`: the gym repo (`data/gym`) and six paper templates.

1. **Knowledge** — work through the deck (acts → hands-ons → capstone). → `01-knowledge.md`
2. **Application ×4** (rep parity: each a fresh ticket-shaped problem of a capstone
   class) — peer audit · verdict matrix · second automation · report-overcount bug.
   → `02..05-application-*.md`
3. **Reinforcement** — CLAUDE.md ideology paragraph. → `06-reinforcement.md`

## Success Metrics

- All 6 issues carry every learner's `<name>:done` label with evidence, and are closed by the trainer.
- Each environment passed a cold peer audit (or has named, justified exceptions).
- Each learner shipped a second automation solo, used at least 3 times on real inputs.

## Gate/Prerequisites

None — first week. Learners need: a machine with node 20+, git, a GitHub account, and
Claude Code on the Max 5x plan.
