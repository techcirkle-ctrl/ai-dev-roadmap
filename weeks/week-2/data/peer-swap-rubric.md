# Peer swap rubric — grading a CLAUDE.md written cold for your repo

You wrote a five-task suite for your own repo. A peer authored a CLAUDE.md for that
repo without speaking to you. Grade their file by running your suite with it in place,
against your own baseline runs.

Score each dimension 1 to 5, with one line of evidence from a real run. No evidence,
no score.

| Dimension | What 5 looks like | Score | Evidence |
|---|---|---|---|
| Accuracy | Every rule is true of the repo today; nothing stale or invented |  |  |
| Behaviour delta | Suite runs visibly improve: fewer questions, fewer wrong turns |  |  |
| Scope fit | Nothing in the file belongs at another scope (global, directory, local) |  |  |
| Always-on tax | Short enough to justify riding along in every session |  |  |
| Keep it? | You would commit this file with at most minor edits |  |  |
